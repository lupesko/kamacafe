# Data Model: Managed Static Deployment

The feature adds release metadata and control-plane state, not application user
data. Cloudflare and GitHub persist the operational records; the repository
defines their required shape and validation rules.

## ReleaseCandidate

Represents one immutable upload that may be reviewed and promoted.

| Field | Type | Rules |
|---|---|---|
| `versionId` | string | Required, nonblank, generated by the hosting platform, immutable |
| `sourceRevision` | string | Required full Git commit SHA; immutable |
| `versionUrl` | HTTPS URL | Required, unique to `versionId`, never canonical |
| `canonicalOrigin` | HTTPS origin | Required; exactly `https://kamacafe.lupesko.com` |
| `createdAt` | timestamp | Required and generated when upload succeeds |
| `checks` | set of check results | Required; every release gate must pass before eligibility |
| `artifactIdentity` | provider version identity | Required; binds assets and configuration to `versionId` |
| `status` | enum | `uploaded`, `eligible`, `rejected`, `promoted`, or `superseded` |

### State transitions

```text
build/check failure ───────────────────────────────> rejected
uploaded ── all required checks pass ─────────────> eligible
eligible ── protected human approval + deploy ────> promoted
eligible ── newer candidate chosen/expiry ────────> superseded
promoted ── later release or rollback ────────────> superseded
```

A `rejected` or `superseded` candidate cannot be promoted by the original
workflow run. A new deliberate workflow run is required.

## ProductionDeployment

Represents the active 100% traffic assignment.

| Field | Type | Rules |
|---|---|---|
| `deploymentId` | string | Required, generated by the hosting platform |
| `versionId` | string | Required; references exactly one eligible candidate |
| `trafficPercentage` | number | Exactly `100` for normal production and rollback |
| `canonicalHostname` | hostname | Exactly `kamacafe.lupesko.com` |
| `approvedBy` | actor identifier | Required for production promotion |
| `approvedAt` | timestamp | Required and later than candidate creation |
| `sourceRevision` | string | Must equal the candidate's immutable revision |
| `verification` | set of results | Public HTTPS, route, metadata, header, and release-ID checks |

Only one normal deployment is active. Gradual traffic splitting is out of scope
because a split between Vite versions can serve HTML that references an asset
available only in the other version.

## DeploymentCredential

Represents the external secret used by CI; the token value is never modeled or
recorded in repository artifacts.

| Field | Type | Rules |
|---|---|---|
| `secretName` | string | Exactly `CLOUDFLARE_API_TOKEN` in CI configuration |
| `accountScope` | account identifier | Exactly the account containing the KamaCafe Worker |
| `capabilities` | permission set | Per-Worker Editor after bootstrap; no Global API Key |
| `storageLocation` | enum | Protected source-control secret store only |
| `rotationEvidence` | metadata | Date and operator only; never token material |

## CanonicalOrigin

| Field | Type | Rules |
|---|---|---|
| `scheme` | enum | `https` only |
| `hostname` | string | `kamacafe.lupesko.com` only |
| `httpBehavior` | enum | Redirect to the equivalent HTTPS URL |
| `certificateStatus` | enum | Must be active before acceptance |
| `canonicalMetadata` | URL set | Page and social URLs must all use this origin |

## RollbackRecord

| Field | Type | Rules |
|---|---|---|
| `fromVersionId` | string | Required current faulty or superseded version |
| `toVersionId` | string | Required previously deployed known-good version |
| `authorizedBy` | actor identifier | Required authorized maintainer |
| `reason` | string | Required, nonblank operational explanation |
| `startedAt` | timestamp | Required |
| `verifiedAt` | timestamp | Required after canonical public checks pass |
| `duration` | interval | Target no more than 5 minutes |
